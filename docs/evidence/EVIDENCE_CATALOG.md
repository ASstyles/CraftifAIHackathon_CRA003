## 3. Manual Checklist for Interactive GUI Canvas Inspection

If an evaluator wishes to inspect the active PipeGen GUI interactive canvas:
1. Ensure WSLg or an X11 server is running (`DISPLAY=:0`).
2. Launch PipeGen:
   ```bash
   /usr/local/bin/pipegen
   # or directly:
   /opt/PipeGen/PipeGenApp --no-sandbox
   ```
3. Sign in using your registered CraftifAI credentials.
4. From the Project Selection dashboard, select project:
   `Parallel Webcam Person Detection and Pose` (UUID: `b76a3ca5-5761-42e2-b55c-a37885395116`).
5. Click **Pipeline IR** tab to visualize the interactive 8-node Directed Acyclic Graph.
6. Click **ModelStage** tab to view the compiled TensorRT 10.3 engine layers and tactic profiles.
